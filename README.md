# GLITCHROT
Advanced image forensics engine combining FFT, ELA, PRNU, and EXIF/C2PA metadata extraction into segregated anomaly detection layers. Each layer independently analyzes frequency patterns, error distributions, and sensor artifacts, with RandomForest ML aggregating layer-wise confidence scores for robust classification.
